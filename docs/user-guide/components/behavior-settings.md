# Behavior settings

- [Voxel Settings Slime](voxel-settings-slime.md) — Control how the slime signal spreads and fades.
- [Voxel Settings Ant](voxel-settings-ant.md) — Control the spread and decay of ant food and home pheromones.
- [Voxel Wrap Settings](voxel-wrap-settings.md) — Choose whether particles wrap around the field boundaries.
- [Particle Settings Slime Ant Interaction](particle-settings-slime-ant-interaction.md) — Control how slime and ant populations respond to each other’s signals.
- [Particle Trail Settings](particle-trail-settings.md) — Set the number of recent positions retained in each particle trail.
- [Particle Division Settings](particle-division-settings.md) — Allow particles to divide when their age and neighborhood meet the conditions.
- [Particle Death Settings](particle-death-settings.md) — Remove particles when their age and neighborhood meet the death conditions.
- [Particle Population Settings](particle-population-settings.md) — Set population limits and random division or death.

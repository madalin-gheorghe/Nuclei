# Component reference

Find a component by its role in the workflow. Each page explains its purpose, connections, inputs, outputs, and related examples. Screenshots are taken from the saved V4 definitions where the component appears.

Fresh-component defaults can differ from the saved example values. Use the example’s controls when reproducing its setup.

# City Map

Turn a city map into an environment that guides a slime simulation. The map's light and dark areas become minimum chemoattractant density values across a flat voxel field. Lighter streets receive higher values, attracting particles toward the street network. A second image defines the river as an obstacle, keeping particles out of that area.

As the particles move, they deposit their own signal and reinforce the paths they follow. The resulting network combines the structure of the city map with smaller, self-organized connections. Use this example to explore how a supplied image and the particles' behavior work together to shape the final pattern.

Open it in Rhino 9 with Nuclei V4, pause the existing Trigger, and inspect the mapped field. Reset once with True, return reset to False, and start the Trigger. Pause before editing several inputs or extracting a large result.

Compare the mapper target range first. Keep the source image fixed so the change comes from remapping, then test another image in a copy.

# Examples

These walkthroughs follow the original V4 definitions. Downloads preserve the saved files, and screenshots preserve their layouts. Start with Slime Intro, then explore maps and attractors before moving to growth or 3D.

- [Slime Intro](01-slime-intro.md) — Follow a complete slime setup from a flat field to a visible particle network.
- [Gradient Map](02-gradient-map.md) — Vary sensing across the environment rather than giving every location the same conditions.
- [Minimizing Transport Networks 1](03-minimizing-transport-networks-1.md) — Explore slime paths around selected food regions in a bounded environment.
- [Minimizing Transport Networks 2](04-minimizing-transport-networks-2.md) — Explore a second arrangement of food regions and the networks that emerge between them.
- [City Map](05-city-map.md) — Use image brightness to shape a planar simulation environment.
- [City Map — alternate definition](05-city-map2.md) — Inspect the alternate saved city-map definition using image-based voxel mapping.
- [Attractor Curves 1](06-attractor-curves-1.md) — Use curve-distance selections to organize local density conditions.
- [Attractor Curves 2](07-attractor-curves-2.md) — Explore curve-driven density maps with an additional scalar blending stage.
- [Vector Fields 1](08-vector-fields-1.md) — Guide movement with vectors assigned to the environment.
- [Vector Fields 2](09-vector-fields-2.md) — Map a field evaluated from Grasshopper point charges into the voxel environment.
- [Multiple Populations](10-multiple-populations.md) — Compare several slime groups sharing one environment and solver.
- [Growth 1](11-growth-1.md) — Explore changing populations with division, death, and population settings.
- [Growth 2](12-growth-2.md) — Compare a second saved growth setup using the same families of population controls.
- [Ants Intro — 3D](13-ants-intro-3d.md) — Extend the ant-foraging workflow into a three-dimensional voxel domain.
- [Ants Intro](13-ants-intro.md) — Follow a basic 2D ant-foraging setup from colony positions to food and pheromone fields.
- [Ants Complex](14-ants-complex.md) — Explore multiple food regions with an additional restrictive density map.
- [3D Intro](15-3d-intro.md) — Explore a volumetric slime simulation and convert its field for meshing.
- [Function Voxels](16-function-voxels.md) — Use an implicit function to select a volumetric region and feed it into a simulation and volume conversion.

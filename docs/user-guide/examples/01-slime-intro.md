# Slime Intro

Watch a slime network emerge from particles moving across a flat voxel field. Each particle senses the surrounding chemoattractant signal, turns toward stronger concentrations, and deposits more signal as it moves. Diffusion spreads that signal into nearby cells, while decay gradually removes it, allowing the pattern to change over time.

This example introduces the complete workflow: create the environment, add particles, connect their behavior settings, and run the solver. Follow the trails as local movements develop into connected paths. Use it to learn how sensing, movement, and signal settings influence the network before adding food regions, attractors, or mapped values.

# Version differences

This documentation teaches **V4**, using components from the **Nuclei4** tab and examples from the V4 collection.

| Version | Compatibility | Main role |
| --- | --- | --- |
| V4 — GPU | Rhino 9 on Windows | GPU simulations and previews, slime and ants, voxel mapping, and volume conversion. |
| V3 — CPU | Rhino 8/9 | CPU slime and ant workflows. |
| V2 — Legacy | Rhino 6–9 on Windows | Original slime simulation workflows. |

## Match the example to the plugin

Open V4 definitions with V4. Component identities, parameter layouts, and available features differ between versions. Installing an older package does not provide the V4 solver.

## Older tutorials

Older videos are useful for the underlying ideas, but their component names, controls, and performance may differ. Follow the current component reference for V4 inputs and outputs.

## Saved definitions

Some V4 definitions retain historical component names from earlier versions. The icon and loaded component implementation can be current even when a saved name is older. Use the original V4 example files supplied here, and inspect runtime messages if a definition fails to load.

Keep a copy before opening an older project in a newer plugin version. Reset and inspect the output before assuming that a migrated definition reproduces an earlier result exactly.

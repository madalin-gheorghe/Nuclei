# Nuclei repository instructions

- Keep responses brief and practical.
- Do not pull from or push to GitHub unless the user explicitly asks.
- Preserve unrelated working-tree changes.
- Before the first GitHub push, confirm that the default branch is named `main`.
- Before a push, update `README.md` only for major features or material improvements; do not add minor-change notes.
- Use clear, commit-specific descriptions for committed files and folders.
- Do not store credentials, API keys, or private account information in the repository.
- Run relevant verification before claiming a code, packaging, or documentation change is complete.
